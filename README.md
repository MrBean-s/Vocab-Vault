Simple Django / HTML App to store words from a language you're currently learning


Requirements

A python vevn with the following libraries

(linux - inside the project folder)
python -m venv nameofthevenv       (Dont move the venv cause venv paths are hardcoded)
source nameofthevenv/bin/activate

(With the Venv activated)
pip install django
pip install django-widget-tweaks
pip install Pillow
pip install python-dateutil

(With the Venv activated)
python manage.py createsuperuser
python manage.py makemigrations
python manage.py migrate

sqlite is used as a db, no setup required.

python manage.py runserver
